# CASE-002 — Pacific Health Network

**Cliente:** Pacific Health Network (ficticio)  
**Sector:** Salud  
**Periodo:** 2023–2024  
**Estado:** Finalizado

## Problema
El cliente necesitaba priorizar solicitudes clínicas y generar alertas analíticas.

## Solución
Se desarrolló una plataforma de clasificación basada en machine learning y un panel web para revisión humana.

## Tecnologías
Python, scikit-learn, MLflow, FastAPI, React.

## Resultados simulados
- 82% de precisión en el conjunto de validación.
- 40% menos tiempo en clasificación inicial.
- Flujo de revisión humana incorporado.

## Evidencia relevante
Experiencia en ML, APIs y sistemas con revisión humana.

## No demostrado
No existe evidencia de uso de datos financieros ni de migraciones cloud a gran escala.

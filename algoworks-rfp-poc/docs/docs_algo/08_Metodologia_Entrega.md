# Metodología de entrega — Simulada

## Fase 1: Descubrimiento
- Identificar stakeholders.
- Inventariar fuentes de datos.
- Definir requisitos funcionales y no funcionales.
- Identificar riesgos y dependencias.

**Duración de referencia:** 2 semanas.

## Fase 2: Arquitectura y diseño
- Arquitectura objetivo.
- Modelo de datos.
- Integraciones.
- Seguridad y observabilidad.
- Plan de migración.

**Duración de referencia:** 3 semanas.

## Fase 3: Piloto
- Implementación de un flujo prioritario.
- Pruebas.
- Validación con usuarios.

**Duración de referencia:** 6–8 semanas.

## Fase 4: Escalamiento
- Industrialización.
- Automatización.
- Transferencia de conocimiento.
- Operación.

**Duración:** por definir según alcance.

## Importante
Los tiempos son referencias simuladas. No deben presentarse como compromisos contractuales.

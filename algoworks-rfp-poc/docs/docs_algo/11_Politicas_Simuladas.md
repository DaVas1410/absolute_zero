# Prácticas de seguridad y gobierno — Simuladas

## Controles disponibles
- Cifrado en tránsito mediante TLS.
- Cifrado en reposo cuando la plataforma lo soporta.
- Gestión de secretos mediante un gestor de secretos.
- Control de acceso basado en roles.
- Registro de auditoría para operaciones críticas.
- Revisión de dependencias de software.
- Escaneo automatizado de vulnerabilidades en CI/CD.

## Gobierno de datos
- Definición de propietarios de datos.
- Catálogo de fuentes.
- Reglas de calidad.
- Registro de linaje cuando técnicamente sea posible.

## Advertencia
Este documento describe prácticas simuladas. No afirma certificaciones ISO, SOC, PCI-DSS u otras. Si un RFP exige una certificación concreta, la respuesta debe marcarla como "requiere validación".

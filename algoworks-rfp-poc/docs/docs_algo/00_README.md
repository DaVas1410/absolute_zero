# Kit de datos simulados — Reto Algoworks

Este paquete fue creado exclusivamente para el Hackathon de Innovación Aplicada Yachay Tech.

## Objetivo
Permitir que los equipos construyan una prueba de concepto de IA para apoyar la preparación de una respuesta a RFP, sin utilizar información confidencial ni propuestas reales.

## Caso central
El RFP simulado corresponde a **AndesFin Cooperativa Financiera**, una organización ficticia que busca modernizar su plataforma de datos y analítica.

## Qué contiene
- `01_RFP_AndesFin.pdf`: solicitud simulada del cliente.
- `02_Perfil_Algoworks_Simulado.md`: perfil ficticio del proveedor.
- `03_Catalogo_Capacidades.csv`: capacidades, tecnologías y evidencias.
- `04` a `07`: casos de éxito ficticios, algunos relevantes y otros parcialmente relevantes.
- `08_Metodologia_Entrega.md`: metodología de implementación.
- `09_Equipo_Expertos.csv`: perfiles ficticios.
- `10_Referencias_Proyectos.csv`: proyectos históricos ficticios.
- `11_Politicas_Simuladas.md`: prácticas de seguridad y gobierno.
- `12_Repositorio_Conocimiento.json`: registros estructurados para sistemas RAG/LLM.
- `13_Conversaciones_Especialistas.md`: respuestas ficticias de especialistas.
- `14_Rubrica_Contenido_RFP.csv`: estructura esperada del RFP y criterios de cobertura.

## Intención del dataset
El conjunto contiene información:
- directamente relevante;
- indirectamente relevante;
- irrelevante pero plausible;
- información incompleta que debe ser marcada como "requiere validación".

Los participantes NO deben asumir que todo lo encontrado debe incorporarse a la propuesta.

## Criterios que el prototipo debería poder demostrar
1. Recuperación de información relevante.
2. Trazabilidad hacia la fuente.
3. Explicación de por qué una evidencia fue seleccionada.
4. Detección de información que requiere validación humana.
5. Generación de una estructura o borrador de respuesta.

Toda la información de este paquete es ficticia.

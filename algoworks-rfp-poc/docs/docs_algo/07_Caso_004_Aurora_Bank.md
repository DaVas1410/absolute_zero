# CASE-004 — Aurora Bank

**Cliente:** Aurora Bank (ficticio)  
**Sector:** Servicios financieros  
**Periodo:** 2021–2023  
**Estado:** Finalizado

## Problema
El banco necesitaba consolidar información de clientes y generar indicadores de riesgo desde varias fuentes.

## Solución
Se construyó un data lakehouse con procesos de ingesta, controles de calidad, catálogo de datos y APIs de consulta.

## Tecnologías
Python, SQL, Azure, PostgreSQL, APIs REST.

## Resultados simulados
- 9 fuentes integradas.
- 22 controles de calidad.
- Reducción de 60% en el tiempo de consolidación mensual.

## Evidencia relevante
Experiencia en servicios financieros, integración, datos y gobierno.

## Limitación
El documento no acredita certificaciones regulatorias específicas ni garantiza experiencia con el core bancario de AndesFin.

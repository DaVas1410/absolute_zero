# Documento histórico — Programa de educación digital

**Cliente:** EducaPlus (ficticio)  
**Año:** 2023

Este proyecto implementó una plataforma de contenidos educativos con autenticación, analítica de usuarios y aplicación móvil.

## Resultado
- 25.000 usuarios registrados.
- Aplicación móvil desarrollada en React Native.
- Dashboard de participación.

## Nota
El proyecto es realista como referencia tecnológica, pero su pertinencia para el RFP de AndesFin es limitada. No contiene evidencia de plataforma financiera ni de integración de datos a escala.

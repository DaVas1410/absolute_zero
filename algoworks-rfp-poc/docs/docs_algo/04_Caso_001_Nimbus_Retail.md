# CASE-001 — Nimbus Retail Group

**Cliente:** Nimbus Retail Group (ficticio)  
**Sector:** Retail  
**Periodo:** 2024–2025  
**Estado:** Finalizado

## Problema
Nimbus tenía datos de ventas, inventario y clientes distribuidos en cuatro sistemas. Los reportes semanales requerían consolidación manual.

## Solución
Se implementó una arquitectura de datos con pipelines ELT, un modelo analítico centralizado, controles de calidad y APIs para exponer indicadores a aplicaciones internas.

## Tecnologías
Python, SQL, dbt, AWS, Terraform, PostgreSQL.

## Resultados simulados
- Reducción del tiempo de preparación de reportes de 3 días a 5 horas.
- 18 fuentes integradas.
- 27 reglas de calidad automatizadas.

## Evidencia relevante para RFP
Experiencia demostrable en integración de fuentes, pipelines, calidad de datos y arquitectura cloud.

## No demostrado
No incluye migración de un core bancario ni integración con sistemas regulatorios.
